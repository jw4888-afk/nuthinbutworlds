NUTHING BUT WORLDS — CLOUDFLARE PAGES FILES

UPLOAD METHOD
1. Sign in to Cloudflare.
2. Open Workers & Pages.
3. Choose Create application > Pages > Upload assets.
4. Enter a project name such as: nuthingbutworlds
5. Upload the ZIP file named nuthingbutworlds-cloudflare.zip.
6. Click Deploy site.
7. After deployment, open Custom domains and add:
   nuthingbutworlds.com
8. Also add www.nuthingbutworlds.com if desired.

IMPORTANT
- The homepage file must remain named index.html.
- Replace hello@nuthingbutworlds.com in index.html when your email is ready.
- You can later add YouTube, Suno, Amazon book, NFT, and social links.
